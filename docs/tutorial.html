NewsScraper Lab

本頁指導如何以 Python 撰寫新聞資訊爬蟲，搭配單元／整合測試， 並用 Harness 實踐 Loop → Verify → Debug 工程迴圈。

1. 系統架構與資料流

爬蟲拆成：擷取 → 解析 → 去重 → 搜尋 → 儲存。協調器只編排流程。

1.5 搜尋功能

爬取後可依關鍵字篩選；也可對既有 JSONL 離線搜尋。

flowchart TD A[新聞列表] --> B{有 query?} B -->|否| C[回傳全部] B -->|是| D[拆關鍵字] D --> E{match_all?} E -->|是| F[每個詞都要命中] E -->|否| G[任一詞命中即可] F --> H[命中列表] G --> H 
py -3 -m src.news_scraper.cli --demo -q "測試" -o out/hits.jsonl
py -3 -m src.news_scraper.cli --search-file out/demo.jsonl -q "Loop Debug" --match-all
py -3 -m src.news_scraper.cli --demo -q "python" --fields tags
  • 預設搜尋欄位：title、summary、source、tags（不分大小寫）
  • 多關鍵字預設「任一命中」；加 --match-all 改為「全部命中」
  • 模組：src/news_scraper/search.py

2. 單元測試與整合測試

類型範圍外網範例
單元測試 @pytest.mark.unit 單一函式／類別 否（fixture／fake） tests/unit/test_parser.py
整合測試 @pytest.mark.integration Fetcher + Parser + Store 管線 否（本機 HTTPServer） tests/integration/test_pipeline.py
flowchart TD S[寫規格 / 失敗測試] --> R[實作最小程式] R --> U[跑單元測試] U -->|失敗| D[Debug 單一層] D --> R U -->|通過| I[跑整合測試] I -->|失敗| D2[Debug 介面契約] D2 --> R I -->|通過| Done[可交付 / 重構]
原則：單元測「規則」，整合測「接線」。不要在單元測試打真實新聞網站。

3. 程式註解教學

本專案註解分兩層： 【語法】給初學者看「這行 Python 在幹嘛」； 【註解教學】／【初學者導讀】說明設計為什麼這樣寫。

類型用途本專案範例
模組開頭【初學者導讀】 列出本檔會用到的語法清單 search.py、models.py
行內【語法】 解釋型別標註、推導式、* 關鍵字參數、f-string 等 搜尋 【語法】 即可跳著讀
類別／函式 docstring 參數、回傳、例外契約 NewsArticle、HttpFetcher.get
【註解教學】 設計意圖（為何拆層、依賴注入） Fetcher 獨立、demo 模式
測試名稱 本身就是可讀規格 test_rss_parser_skips_empty_title

建議寫法

# 好：說明約束與原因，或初學者看不懂的語法
# 【語法】* 後面只能用關鍵字傳參數，避免位置傳錯。
def parse(self, content: str, *, source: str = "") -> list: ...

# 差：複述語意
# 把 source 設成預設空字串
def parse(self, content: str, *, source: str = "") -> list: ...

註解檢查清單

  • 公開 API 是否有 docstring（參數／回傳／例外）？
  • 進階語法（推導式、| 聯集型別、with）是否有【語法】說明？
  • 是否避免過期註解？程式變了註解與文件要一起改。

4. Harness & Loop Engineering

Harness（測試鞍具）把「跑測試 → 判斷結果 → 給除錯提示 → 再跑」固化成可重複腳本， 對應工程迴圈 Loop → Verify → Debug。

stateDiagram-v2 [*] --> Loop Loop --> Verify: 執行 pytest Verify --> Pass: exit_code == 0 Verify --> Debug: exit_code != 0 Debug --> Loop: 依 hints 修正後重試 Pass --> [*]: 寫入 harness 報告 note right of Debug 常見 hints： 缺套件 / AssertionError / 連線逾時 / 權限 end note 
python harness/loop_verify_debug.py --cov
python harness/loop_verify_debug.py --unit-only --max-loops 3
python harness/loop_verify_debug.py --once

報告輸出：out/harness/last_run.json

5. 動手執行

  1. 安裝依賴：pip install -r requirements.txt
  2. 離線示範：python -m src.news_scraper.cli --demo -o out/demo.jsonl
  3. 關鍵字搜尋：python -m src.news_scraper.cli --demo -q "Loop" -o out/hits.jsonl
  4. 單元測試：pytest -m unit
  5. 整合測試：pytest -m integration
  6. 完整 harness：python harness/loop_verify_debug.py --cov
