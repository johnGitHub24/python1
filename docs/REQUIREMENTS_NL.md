## 自然語言怎麼拆解（語法／語意）

用「動詞 + 產物／方式」讀每一條：

| # | 你寫的自然語言 | 動詞（要做什麼） | 產物／約束（做出什麼） | 專案對應位置 |
|---|----------------|------------------|------------------------|--------------|
| 1 | 撰寫 python 爬蟲 新聞資訊程式 | **撰寫** | Python **新聞資訊爬蟲**程式 | `src/news_scraper/` |
| 2 | 使用單元測試與整合測試開發 | **使用…開發** | **單元測試** + **整合測試** 驅動開發 | `tests/unit/`、`tests/integration/` |
| 3 | 轉寫 html 指導教學 & 畫流程圖 mermaid | **轉寫** + **畫** | **HTML 教學** & **Mermaid 流程圖** | `docs/tutorial.html` |
| 4 | 撰寫程式註解教學 | **撰寫** | **程式註解**（教學用途） | 原始碼 `【語法】`／`【註解教學】`；教學頁註解章節 |
| 5 | harness & loop engineering；loop - verify - debug | **工程化** | **Harness**；流程為 **Loop → Verify → Debug** | `harness/loop_verify_debug.py` |

## 各條的「自然語言語法」說明

### 1.「撰寫 python 爬蟲 新聞資訊程式」

- **撰寫**＝要產出可執行程式，不是只講概念  
- **python**＝語言限定  
- **爬蟲**＝自動抓網頁／RSS 資料  
- **新聞資訊**＝領域是新聞內容  
- **程式**＝要有模組／可執行入口（CLI）

### 2.「使用單元測試與整合測試開發」

- **使用 A 與 B 開發**＝開發方式＝測試驅動／測試伴隨  
- **單元測試**＝測單一函式／類別（不連外網）  
- **整合測試**＝測多層接在一起（本機 server 管線）

### 3.「轉寫 html 指導教學 & 畫流程圖 mermaid」

- **轉寫**＝把程式／流程改寫成另一種載體（HTML）  
- **指導教學**＝給人看的教學頁，不是 API 手冊而已  
- **&**＝兩件都要做  
- **畫流程圖 mermaid**＝用 Mermaid 語法畫圖（嵌在 HTML）

### 4.「撰寫程式註解教學」

- **程式註解**＝寫在原始碼裡的說明  
- **教學**＝註解要能教人（語法／為何這樣寫），不是隨便標註

### 5.「harness & loop engineering / loop - verify - debug」

- **harness**（鞍具）＝包住測試、可重複跑的工程腳本  
- **loop engineering**＝用迴圈方式做工程驗證  
- **loop - verify - debug**＝三步驟固定順序：  
  1. **Loop** 再跑一次  
  2. **Verify** 檢查過不過  
  3. **Debug** 依失敗提示修正  

（原文 `harmess` 視為 **harness** 拼字。）
